Hướng dẫn cài đặt & sử dụng Tool Word / Excel sang PDF hàng loạt

Đây là bài viết chi tiết mô tả chức năng, cách sử dụng và hướng dẫn khắc phục lỗi cho Tool Word / Excel sang PDF hàng loạt:

CHƯƠNG TRÌNH LÀM ĐƯỢC GÌ?

Chuyển cả một thư mục file Word, Excel (và PowerPoint nếu muốn) sang PDF chỉ bằng một lần bấm.

Điểm khác với các web chuyển đổi trên mạng:

  • File KHÔNG rời khỏi máy bạn. Hợp đồng, hồ sơ nhân sự, số liệu nội bộ không bị tải lên máy chủ của ai cả.
  • Dùng chính Microsoft Office trên máy nên PDF ra giống hệt bản in: không vỡ font tiếng Việt, không lệch bảng.
Đây là lý do đáng để cài một phần mềm nhỏ thay vì mở web: với hồ sơ có thông tin khách hàng, lương thưởng hay số liệu nội bộ, việc tải file lên một trang web lạ là điều nhiều cơ quan không cho phép.

CÁCH DÙNG (4 bước)

  1. Giải nén file ZIP ra một thư mục, bấm đúp SangPDF.exe (phải giải nén trước khi chạy).
  2. BƯỚC 1: chọn thư mục chứa file. Tích loại file cần lấy (Word / Excel / PowerPoint), chọn có lấy cả thư mục con hay không.
  3. BƯỚC 2: chọn nơi lưu PDF — để cạnh file gốc, hoặc vào một thư mục riêng (khi đó có thể giữ nguyên cấu trúc thư mục con).
  4. Xem danh sách bên dưới cho đúng rồi bấm BẮT ĐẦU CHUYỂN. Mỗi file mất khoảng 1 đến 3 giây.

MÁY CẦN CÓ GÌ?

  • Windows 10 hoặc 11 (64-bit). Không cần cài Python.
  • PHẢI có Microsoft Office bản cài đặt trên máy:
    • file Word → cần Microsoft Word
    • file Excel → cần Microsoft Excel
    • file PowerPoint → cần Microsoft PowerPoint
  • WPS Office hoặc Office bản web KHÔNG dùng được. Chương trình tự kiểm tra và báo cho bạn biết ngay khi mở.

MẸO DÙNG

  • "Bỏ qua file đã có PDF": bật sẵn. Nhờ đó nếu đang chạy dở bị ngắt, lần sau chạy lại sẽ tiếp tục chứ không làm lại từ đầu.
  • Riêng Excel có tùy chọn "ép vừa 1 trang ngang" — dùng khi bảng rộng bị cắt mất cột bên phải.
  • Trong lúc chạy, đừng mở Word/Excel làm việc khác, dễ gây xung đột. Cứ để máy chạy.

HAY GẶP

  • "Không mở được Microsoft Office": máy chưa có Office bản cài đặt, hoặc đang có cửa sổ Word/Excel bị treo. Đóng hết Word/Excel (kể cả trong Task Manager) rồi thử lại.
  • Một vài file báo lỗi, còn lại chạy bình thường: file đó có thể đang mở, bị khóa, hoặc hỏng. Xem phần nhật ký để biết file nào.
  • PDF ra bị thiếu cột (file Excel): bật ép vừa 1 trang ngang rồi chạy lại.

LẦN ĐẦU MỞ BỊ WINDOWS CẢNH BÁO? Cửa sổ "Windows protected your PC" hiện ra thì Bấm "More info" -> "Run anyway".

Bảng xanh đó là do file chưa mua chứng thư số, KHÔNG phải virus.

Công cụ miễn phí, không thu phí, không quảng cáo.

Bạn có thể chia sẻ lại cho người khác.
