Hướng dẫn sử dụng công cụ Tách & Gộp Excel

Đây là bài viết chi tiết mô tả chức năng, cách sử dụng và hướng dẫn khắc phục lỗi cho công cụ Tách & Gộp Excel:

Công cụ này KHÔNG cần cài đặt. Nó chạy thẳng trong trình duyệt (Chrome, Edge, Cốc Cốc đều được), nên không có cảnh báo virus, không phải giải nén, dùng được cả trên máy Mac và điện thoại. File của bạn được xử lý ngay trong máy bạn — trang này không gửi file đi đâu cả.

CHƯƠNG TRÌNH LÀM ĐƯỢC GÌ?

Tách một bảng thành nhiều file:

  • Một bảng 2.000 dòng dữ liệu của 12 phòng ban → 12 file riêng trong vài giây, đóng gói sẵn thành một file ZIP để gửi đi.
  • Chọn cột để tách (ví dụ cột "Phòng ban"), đặt mẫu tên file (ví dụ Phong_{giá trị}).
  • Xem trước sẽ ra bao nhiêu file, mỗi file bao nhiêu dòng, rồi mới tải về.

Gộp nhiều file về một bảng:

  • Cuối tuần nhận về 12 file đã sửa → gộp lại thành một bảng.
  • Ghép theo TÊN CỘT chứ không theo vị trí, nên phòng nào tự đổi thứ tự cột hay thêm cột vẫn ghép đúng.
  • Báo rõ trước khi gộp: file nào thiếu cột, file nào có cột lạ, file nào rỗng — để bạn phát hiện sai sót trước, không phải sau.

CÁCH DÙNG — TÁCH FILE (4 bước)

  1. Kéo file Excel vào ô ở tab "Tách file".
  2. Chọn sheet, cho biết dòng tiêu đề nằm ở dòng mấy, chọn cột muốn tách theo.
  3. Bấm Xem trước để thấy sẽ ra bao nhiêu file, mỗi file bao nhiêu dòng.
  4. Bấm Tách và tải về — trình duyệt tải xuống một file ZIP chứa toàn bộ file con.

CÁCH DÙNG — GỘP FILE (4 bước)

  1. Kéo tất cả các file cần gộp vào ô ở tab "Gộp file" (chọn nhiều file cùng lúc được).
  2. Cho biết dòng tiêu đề nằm ở dòng mấy.
  3. Bấm Kiểm tra cấu trúc — đọc kỹ phần cảnh báo màu vàng nếu có.
  4. Bấm Gộp và tải về.

NHỮNG ĐIỀU CẦN BIẾT

  • Dữ liệu không rời khỏi máy bạn. Toàn bộ xử lý chạy bằng trình duyệt trên máy tính của bạn — bạn có thể ngắt mạng rồi dùng vẫn chạy bình thường.
  • File kết quả giữ số liệu, không giữ công thức và không giữ màu sắc, độ rộng cột. Số vẫn là số và ngày vẫn là ngày, nên SUM và lọc theo ngày vẫn chạy bình thường.
  • File trên khoảng 50.000 dòng có thể làm trình duyệt chậm vài chục giây. Cứ chờ, đừng đóng tab.
  • File .xls đời cũ vẫn đọc được. Nếu gặp file lỗi, cách chữa nhanh nhất là mở bằng Excel rồi lưu lại thành .xlsx.
  • Muốn dùng khi không có mạng: bấm Ctrl+S lưu trang về máy, sau đó mở file đã lưu là dùng được.

HAY GẶP

  • Không thấy tên cột trong danh sách: kiểm tra lại số "dòng tiêu đề". Nếu file có dòng tiêu đề lớn ở trên cùng thì tiêu đề thật thường nằm ở dòng 2.
  • Tách ra quá nhiều file: bạn đang chọn nhầm cột (ví dụ chọn cột Họ tên thì mỗi người thành một file). Xem lại phần Xem trước trước khi tải.
  • Gộp xong thấy nhiều ô trống: các file nguồn không thống nhất tên cột. Phần "Kiểm tra cấu trúc" có liệt kê file nào thiếu cột gì.

Công cụ miễn phí, không thu phí, không quảng cáo.

Bạn có thể chia sẻ lại cho người khác.
