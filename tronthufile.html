Hướng dẫn cài đặt & sử dụng Tool Trộn Thư Ra File Riêng

Đây là bài viết chi tiết mô tả chức năng, cách sử dụng và hướng dẫn khắc phục lỗi cho Tool Trộn Thư Ra File Riêng:

CHƯƠNG TRÌNH LÀM ĐƯỢC GÌ?

Mail Merge (trộn thư) có sẵn của Word chỉ cho ra MỘT file dài gộp tất cả mọi người. Công cụ này cho ra file RIÊNG cho từng người, tên file đặt tự động theo dữ liệu (ví dụ: NV001_Nguyen Van A.docx), và xuất thẳng ra PDF nếu bạn muốn.

Hợp với các loại văn bản:

  • Quyết định, giấy mời, thông báo gửi từng người.
  • Hợp đồng mẫu, phiếu lương, giấy chứng nhận.
  • Bất cứ văn bản nào cùng một mẫu nhưng khác nội dung từng người.

Những tiện ích thêm:

  • Đọc số thành chữ tiếng Việt cho dòng "bằng chữ" trong quyết định, hợp đồng, phiếu chi.
  • Định dạng ngày kiểu hành chính: "ngày 05 tháng 09 năm 2026".
  • Lọc dòng theo điều kiện — chỉ làm những người thuộc một phòng ban chẳng hạn.
  • Xem trước danh sách tên file trước khi chạy.
  • Tên file trùng nhau thì tự thêm _2, không bao giờ ghi đè mất file.

CÁCH DÙNG (4 bước)

  1. Giải nén file ZIP ra một thư mục, bấm đúp TronThu.exe (phải giải nén trước khi chạy).
  2. BƯỚC 1: chọn file Excel danh sách. Cho biết dòng tiêu đề nằm ở dòng số mấy (thường là 1; nếu file có dòng tiêu đề lớn ở trên thì là 2).
  3. BƯỚC 2: chọn mẫu Word. Nếu chưa có mẫu, bấm nút "Tạo mẫu sẵn từ danh sách cột" — chương trình sinh ra một file Word mẫu có sẵn tên các trường, bạn mở ra soạn lại nội dung theo ý mình.
  4. BƯỚC 3: chọn thư mục lưu, chọn cách đặt tên file, chọn Word hay PDF, rồi bấm BẮT ĐẦU TẠO FILE.

CÁCH VIẾT TRƯỜNG TRONG MẪU WORD

Trong file Word, chỗ nào cần điền dữ liệu thì gõ hai ngoặc nhọn kèm đúng tên cột trong Excel:

Gõ trong mẫu WordKết quả trong file tạo ra
{{Họ và tên}}Nguyễn Văn An
{{Phòng ban:hoa}}KỸ THUẬT
{{Lương}}12.500.000
{{Lương:chữ}}Mười hai triệu năm trăm nghìn
{{Ngày ký:ngày}}ngày 05 tháng 09 năm 2026
{{Lương:thô}}12500000 (giữ nguyên như trong Excel)

Lưu ý: tên trong hai ngoặc phải viết giống hệt tiêu đề cột trong Excel (không cần đúng chữ hoa/thường). Bấm nút "Kiểm tra trường trong mẫu" để chương trình soát giúp bạn — đây là lỗi hay gặp nhất, và nếu không soát thì file tạo ra vẫn còn nguyên chữ {{...}}.

Trường đặt được ở mọi chỗ: thân bài, trong bảng, đầu trang, chân trang. Định dạng chữ (in đậm, cỡ chữ, màu) được giữ nguyên.

ĐẶT TÊN FILE KẾT QUẢ

Ô "Đặt tên file theo" dùng cùng cách viết đó:

  • {{Mã NV}}_{{Họ và tên}} → NV001_Nguyen Van An.docx
  • QD_{stt} → QD_1.docx, QD_2.docx ...

MÁY CẦN CÓ GÌ?

  • Windows 10 hoặc 11 (64-bit). Không cần cài Python.
  • Xuất file Word (.docx): KHÔNG cần cài Microsoft Word.
  • Xuất PDF: máy PHẢI có Microsoft Word bản cài đặt (WPS Office hoặc Word bản web không dùng được).
  • Mẫu phải là file .docx. File .doc đời cũ hãy mở bằng Word rồi lưu lại thành .docx.

NHỮNG ĐIỀU CẦN BIẾT

  • Trường đặt trong ô văn bản (Text Box) không thay được. Thân bài, bảng, đầu trang và chân trang thì được. Nếu mẫu của bạn dùng Text Box, hãy chuyển nội dung đó ra ngoài.
  • Xuất PDF chạy chậm hơn vì mỗi file phải qua Microsoft Word — khoảng 1 đến 3 giây một file. Cứ để máy làm việc.
  • Trong lúc chạy, nên đóng các cửa sổ Word đang mở để tránh xung đột.

HAY GẶP

  • File kết quả vẫn còn chữ {{Tên gì đó}}: tên cột viết sai chính tả so với Excel. Bấm "Kiểm tra trường trong mẫu" để biết sai ở đâu.
  • Xuất PDF báo lỗi: đóng hết cửa sổ Word đang mở rồi thử lại. Hoặc chọn Word (.docx) rồi tự chuyển sang PDF sau.
  • Không ghi được file: thư mục đang mở file trong Word, hoặc thư mục không cho ghi. Hãy chọn thư mục khác trong Documents.

LẦN ĐẦU MỞ BỊ WINDOWS CẢNH BÁO? Cửa sổ "Windows protected your PC" hiện ra thì Bấm "More info" -> "Run anyway".
