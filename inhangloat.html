Hướng dẫn cài đặt & sử dụng Tool In hàng loạt

Đây là bài viết chi tiết mô tả chức năng, cách cài đặt và hướng dẫn khắc phục lỗi cho Tool In hàng loạt:

Tính năng chính:

  • Tốc độ xử lý cực nhanh.
  • IN HÀNG LOẠT - Công cụ in nhiều hồ sơ cùng lúc
  • Bản miễn phí - dùng cho Windows

    • CHƯƠNG TRÌNH LÀM ĐƯỢC GÌ?

    - In hàng loạt file .docx, .xlsx/.xls và .pdf trong một thư mục. - Chọn máy in, số bản in, in 1 mặt / 2 mặt (lật xuôi hoặc lật ngược). - In màu hoặc trắng đen. - Chọn phạm vi trang: in tất cả, hoặc từ trang X đến trang Y. Có thể đặt riêng phạm vi trang cho từng file ở màn hình xem trước. - Tạm dừng giữa chừng và in tiếp từ đúng chỗ đang dừng.

    CÁCH DÙNG (3 bước)

    1. Giải nén toàn bộ file ZIP ra một thư mục. 2. Mở thư mục vừa giải nén, bấm đúp vào file: InHangLoat.exe 3. Chọn thư mục chứa hồ sơ -> chọn máy in -> đặt số bản, in 2 mặt, màu/trắng đen, phạm vi trang -> bấm In.

    LẦN ĐẦU MỞ BỊ WINDOWS CẢNH BÁO (NẾU CÓ)?

    Windows hiện bảng xanh "Windows protected your PC" là do file chưa mua chứng thư số, KHÔNG phải virus. Cách mở: bấm "More info" (Thông tin thêm) -> bấm "Run anyway" (Vẫn chạy). Nếu phần mềm diệt virus xóa mất file: mở phần mềm diệt virus, vào mục Quarantine/Cách ly, chọn Restore và thêm thư mục này vào danh sách loại trừ (Exclusion).

    MÁY CẦN CÓ GÌ?

    - Windows 10 hoặc 11 (64-bit). - Muốn in file Word (.doc/.docx): máy phải có Microsoft Word. - Muốn in file Excel (.xls/.xlsx): máy phải có Microsoft Excel. - File PDF: in được ngay, không cần cài gì thêm.

    LỖI CÓ THỂ GẶP

    - Danh sách máy in hiện dòng "(THIẾU pywin32 ...)": bản tải về bị thiếu file. Hãy xóa thư mục cũ, tải lại file ZIP và giải nén lại toàn bộ. - In file Word/Excel báo lỗi: đóng hết cửa sổ Word/Excel đang mở rồi thử lại. Bản web hoặc WPS Office không dùng được. - In ra bị lệch, sai khổ giấy: kiểm tra lại cài đặt mặc định của máy in trong Control Panel > Devices and Printers.

  • Công cụ miễn phí, không thu phí, không quảng cáo.
  • Bạn có thể chia sẻ lại cho người khác.
